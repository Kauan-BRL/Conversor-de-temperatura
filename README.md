# Conversor de temperatura 🌡️

>Este projeto permite converter a temperatura de uma escala para outra de forma intuitiva. As escalas suportadas são: Kelvin (K), Fahrenheit (°F) e Celsius (°C).

## Funcionalidades

- Conversão de temperaturas entre Celsius, Fahrenheit e Kelvin.

- Validação de entradas e tratamento de escalas idênticas.

## Pré-requisitos

- Certifique-se de que a sua versão do Python é igual ou superior à 3.12.

- Caso não possua o Python instalado, baixe-o no site oficial do Python.

## Execução

Para executar o programa a partir da pasta raiz do projeto, abra o terminal e digite o seguinte comando:

python temp.py


## Uso

Após iniciar o programa, siga as instruções do menu interativo:

- Funcionamento: Digite 1, 2, 3 ou 0 para selecionar as escalas de temperatura desejadas e informe o valor numérico a ser convertido.

- Escalas distintas: As escalas de origem e destino devem ser diferentes; caso contrário, o sistema exibirá o aviso:
====== Selecione escalas diferentes! ======

- Encerramento: Digitar 0 em qualquer etapa do menu finaliza a aplicação.

- Validação: Entradas não numéricas são rejeitadas, solicitando a informação novamente.

## Exemplo

Se você selecionar 1 (Celsius), em seguida 3 (Kelvin), e informar o valor 25, o programa retornará:
Temperatura em Kelvin: 298.15K
