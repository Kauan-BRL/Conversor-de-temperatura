# Conversor de temperatura 🌡️
![Linguagem utilizada](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)

> Este projeto lhe permite converter a temperatura de uma escala para outra de seu desejo de forma intuitiva. Os tipos de temperatura possíveis são: Kelvin (K), Fahreinheit (F°) ou Celsius (C°).

## Funcionalidades 

- Conversão de temperaturas
- Tipos de temperaturas: Kelvin, Fahreinheit, Celsius
  
## Execução

1. Clonar o repositório
2. Execute o arquivo "temp.py" no terminal ou em um editor de código

https://github.com/Kauan-BRL/Conversor-de-temperatura

## Uso

Após executar o arquivo, siga as instruções do menu:

- Funcionamento: Digite 1, 2, 3 ou 0 para selecionar as escalas de temperatura e informe o valor desejado.

- Escalas distintas: As escalas de origem e destino devem ser diferentes; caso contrário, aparecerá o aviso
   '====== Selecione escalas diferentes! ======'.

- Encerramento: Digitar 0 em qualquer menu finaliza o programa.

- Validação: Entradas não numéricas são rejeitadas, solicitando a informação novamente.

## Exemplo

Caso selecione 1 (Celsius), em seguida 3 (Kelvin), e informar um valor como: 25, lhe será apresentado: 'Temperatura em Kelvin: 298.15K'.
